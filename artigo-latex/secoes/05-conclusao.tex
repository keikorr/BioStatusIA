\section{Conclusion}
\label{sec:conclusao}

\subsection{Summary of contributions}
This paper presented a modality-agnostic ingestion and multi-domain feature engineering pipeline for heterogeneous biomedical data within the BioStatusIA system. By establishing an automatic structure detection mechanism spanning nine operational modes and implementing the unified \texttt{SinalNormalizado} data contract, the framework decouples file-level readers from mathematical feature extractors. The empirical benchmark across 30 authentic biomedical datasets demonstrated complete ingestion robustness without unhandled exceptions, as well as strict dimensional consistency within each signal and imaging family (18 features for temporal signals, 14 for 2D DICOM, 22 for 3D volumes, and 12 for standard 2D images).

\subsection{Limitations}
Several operational limitations should be acknowledged:
\begin{enumerate}
    \item Structural mode detection relies primarily on file extensions and directory layout rather than deep inspection of internal content; consequently, temporal signals formatted as flat CSV matrices are ingested through the tabular parser.
    \item Processing high-resolution 3D volumetric series (Family F4) incurs considerable memory allocation during 3D GLCM matrix construction, requiring downsampling for large volumetric scans.
    \item The current implementation excludes continuous biomedical audio recordings (Family F2) and clinical endoscopy or ultrasound video sequences (Family F5).
\end{enumerate}

\subsection{Future work}
Future work will focus on integrating content-based semantic classifiers to infer signal origin directly from data distributions, expanding the architecture to support streaming physiological telemetry, and integrating deep neural representations alongside handcrafted radiomic features. Finally, the consolidated feature vectors generated by this pipeline serve as the direct input to the downstream automated modeling, calibration, and AI-assisted clinical reporting stage.

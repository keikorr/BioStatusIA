[CONTEXT: Clinical decision support pipelines for biomedical data are conventionally built around a
single modality, so that ingestion and feature extraction must be re-engineered whenever the input
modality changes.]
[GAP: There is a lack of architectures that infer the structure of an arbitrary biomedical input and
adapt reading, preprocessing and feature extraction without manual reconfiguration.]
[PROPOSAL: This paper presents the ingestion and feature-engineering stage of BioStatusIA v3, which
automatically classifies raw input into one of nine structural modes, validates it, and normalizes
every supported modality into a single data contract.]
[METHOD: Three biomedical signal families are supported --- temporal physiological signals (F1),
two-dimensional DICOM imaging (F3) and three-dimensional volumes (F4) --- alongside tabular clinical
records and plain two-dimensional images. A family-specific reader converts each input into the
\texttt{SinalNormalizado} contract, from which adaptive preprocessing and multi-domain feature
extraction produce a classifier-ready feature vector.]
[RESULTS: The pipeline was exercised over thirty real biomedical benchmark datasets covering all
families in scope; detected structural mode and feature-vector dimensionality are reported per
dataset and per family.]
[IMPLICATION: The results indicate that structural detection operates on the physical organization of
the data rather than on its declared clinical semantics, which is discussed as both a strength and a
limitation.]
\end{abstract}
